# Northeastern Pennsylvania Intergroup of Alcoholics Anonymous

Storage repository for Northeastern Pennsylvania Intergroup of Alcoholics Anonymous, managed by the d39admin app.

## What's in here

- Meeting minutes drafts and published copies.
- Schedule, treasury, attendance.
- Anything else the admin tool publishes from.

## Don't edit by hand

d39admin commits to this repo on your behalf. If you edit files
directly, the next publish from the admin tool may overwrite your
changes. If you need to fix something the tool got wrong, fix it
in the tool — that way it stays fixed across publishes.
